Entry for the [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f)
bounty on [make.fun](https://make.fun): one funny line, a single sentence of at
most 200 characters, judged pairwise by a house judge on surprise ending,
everyday truth, and economy of words.

## The line

> I asked my bank for a loan, and it asked me for one back.

## How it works

`main.py` writes the line to `/output/entry.txt` (57 characters, one sentence).
Deterministic: every run produces the exact same bytes.

```sh
python3 main.py
cat /output/entry.txt
```
